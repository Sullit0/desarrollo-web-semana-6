## Flujo de trabajo

1. Cada uno hace `git checkout <su-rama>` y trabaja ahí.
2. Commits y push a la rama propia: `git push origin <su-rama>`.
3. Al finalizar, **Sullit0** mergea cada rama a `main`.
4. Plazo máximo de entrega: **12:45 h**.

## Reglas

- Solo HTML, CSS y JavaScript puro (sin librerías externas).
- Funciones y variables con nombres descriptivos en español.
