## Flujo de trabajo

1. **Anyelo** empieza primero creando el esqueleto HTML/CSS/JS base y lo pushea a `main`.
2. Los demás hacen `git pull origin main` en su rama y trabajan en paralelo.
3. Commits y push a la rama propia: `git push origin <su-rama>`.
4. Al finalizar, **Anyelo** mergea cada rama a `main` y resuelve conflictos.
5. Plazo máximo de entrega: **12:45 h**.

## Reglas

- Solo HTML, CSS y JavaScript puro (sin librerías externas).
- Funciones y variables con nombres descriptivos en español.
